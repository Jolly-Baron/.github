# Support

If you need help with Jolly-Baron projects, please:

- Check the [documentation](https://github.com/Jolly-Baron/Jolly-Baron-Translator/wiki) first (if available).
- Search existing [Issues](https://github.com/Jolly-Baron/Jolly-Baron-Translator/issues) to see if your question has already been answered.
- If not, open a new Issue and provide as much detail as possible.

For security vulnerabilities, please see our [Security Policy](SECURITY.md).

# Contributing to Jolly-Baron projects 🎉

Thank you for considering a contribution! We welcome everyone.

## How to help
- Report bugs via [Issues](link to main repo issues).
- Suggest new features by opening an Issue with your idea.
- Submit Pull Requests with fixes or improvements.

### Code style
Please follow the coding style already used in the project. If in doubt, ask in the discussion.

### Pull Request process
1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Open a Pull Request with a clear description.
5. Wait for review by the maintainers.

**First time contributing to open source?** Check out this handy [guide](https://opensource.guide/how-to-contribute/).
